Marks agents that another agent started. Their composer gets a "↳ Worker of <parent>" pill, so you can tell a worker from the agent that runs the job before you ask it something.

Tapping the pill opens a "Parent agent" panel with the parent's title and status, and a button that opens the parent.

It reads the parent link Paseo already stores on each agent. It sends nothing anywhere. A parent on another host, or an archived parent, shows its id instead of its title.
