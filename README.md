# paseo-plugins

[Paseo](https://paseo.sh) plugins by crockalet.

| Plugin | What it does |
| --- | --- |
| [codex-pets](plugins/codex-pets) | Shows one of your Codex pets in Paseo, acting out the most urgent state across your workspaces on every host. |
| [worker-of](plugins/worker-of) | Marks agents that another agent started with a "Worker of <parent>" pill that opens the parent. |

Install one straight from this repo:

```bash
paseo plugin add git:crockalet/paseo-plugins:plugins/codex-pets
paseo plugin add git:crockalet/paseo-plugins:plugins/worker-of
```
